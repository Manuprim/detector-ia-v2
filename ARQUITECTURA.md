# Arquitectura Detector IA v2.0

## Arquitectura General

Usuario
↓
Aplicación Web
↓
Motor de Análisis
↓
Clasificador
↓
Resultado

---

## Componentes

### Aplicación Web

Responsable de:

- Recibir texto
- Mostrar resultados
- Generar reportes

---

### Motor de Análisis

Responsable de:

- Analizar vocabulario
- Analizar estilo
- Analizar patrones lingüísticos
- Calcular métricas

---

### Clasificador

Responsable de determinar:

- Humano
- IA Asistido
- IA Predominante

---

## Flujo

1. Usuario pega texto.

2. El sistema analiza:

- Longitud
- Vocabulario
- Complejidad
- Variabilidad

3. El clasificador procesa la información.

4. El sistema genera un resultado.

---

## Salida

El usuario recibe:

- Clasificación
- Nivel de confianza
- Explicación
- Evidencia
